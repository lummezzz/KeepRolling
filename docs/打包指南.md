# Keep Rolling（滚滚车流）— Android 本地打包指南

> 一款可在手机上自由搭建道路网络、实时观看车流的地面交通微观模拟器。
> 技术栈：Kotlin + Jetpack Compose + MVVM，仅 Android 平台。

---

## 一、环境准备（只需一次）

| 工具 | 版本要求 | 说明 |
|---|---|---|
| Android Studio | Koala (2024.1) 或更新 | 自带 JDK 17 与 Android SDK，够用 |
| JDK | 17 | Android Studio 自带，无需单独安装 |
| Android SDK | API 34 (compileSdk) | 首次编译时 AS 会自动提示下载 |

**你已经在用 Android Studio，环境基本齐了。** 唯一注意：首次打开项目若提示下载
"Android SDK Platform 34" / "Build-Tools"，点一下确认即可（已配置阿里云镜像的仅是依赖包，SDK 组件仍走官方渠道，如有代理更顺）。

## 二、打开并运行项目

1. Android Studio → **File → Open** → 选择 `KeepRolling` 文件夹（注意是项目根目录，含 `settings.gradle.kts` 的那层）。
2. 等待 Gradle Sync 完成（首次会下载 Gradle 8.7 发行包 + 依赖，走的是腾讯云/阿里云镜像，一般 3~10 分钟）。
3. 手机插电脑，**开启开发者模式 + USB 调试**，点 AS 的 ▶ Run 直接真机运行调试。

## 三、打 Debug APK（自己装、自己玩）

**方式 A：图形界面**
`Build → Build Bundle(s) / APK(s) → Build APK(s)`，完成后右下角弹通知，点 `locate` 找到：
`app/build/outputs/apk/debug/app-debug.apk`，发到手机上直接安装。

**方式 B：命令行**（项目根目录）
```bash
gradlew.bat assembleDebug
```
产物路径同上。

## 四、打 Release APK（正式签名版，体积更小）

### 1. 生成签名密钥（只需一次，密码自己定，记牢）
Android Studio 菜单 `Build → Generate Signed Bundle / APK → APK → Create new...`
填一个保存路径（如 `keeprolling.jks`）和密码，其余默认，生成 keystore。

### 2. 配置签名（推荐做法）
在项目根目录建 `keystore.properties`（**此文件不要外传、不要提交 Git**）：
```properties
storeFile=../keeprolling.jks
storePassword=你的密码
keyAlias=你的别名
keyPassword=你的密码
```
然后在 `app/build.gradle.kts` 的 `android { }` 里加：
```kotlin
signingConfigs {
    create("release") {
        val props = java.util.Properties()
        val f = rootProject.file("keystore.properties")
        if (f.exists()) props.load(f.inputStream())
        storeFile = file(props.getProperty("storeFile") ?: "")
        storePassword = props.getProperty("storePassword")
        keyAlias = props.getProperty("keyAlias")
        keyPassword = props.getProperty("keyPassword")
    }
}
buildTypes {
    release {
        isMinifyEnabled = false
        signingConfig = signingConfigs.getByName("release")
    }
}
```

### 3. 出包
```bash
gradlew.bat assembleRelease
```
产物：`app/build/outputs/apk/release/app-release.apk`

## 五、高频报错排查

| 症状 | 原因与解法 |
|---|---|
| Sync 卡在下载 Gradle | 换镜像：`gradle/wrapper/gradle-wrapper.properties` 已指向腾讯云镜像；也可挂代理 |
| `Could not resolve` 某依赖 | 阿里云镜像偶发不同步新版包：删掉 `settings.gradle.kts` 里阿里云两行，改回 `google()` / `mavenCentral()` 直连（需代理） |
| `SDK location not found` | `local.properties` 缺失或 SDK 路径不对，让 AS 重新 Sync 自动生成 |
| `Unsupported class file major version` | JDK 版本不对：AS 设置 `Gradle JDK` 选 17 |
| 改了代码不生效 | `Build → Clean Project` 后重跑 |
| 真机安装失败 | 手机上卸载旧版本再装（签名不一致时必须先卸载） |

## 六、边界说明

- 本指南只覆盖**本地打包**，不涉及应用商店上架与资质审核。
- 路网存档保存在 App 私有目录，卸载 App 会一并删除；重要路网记得多点几次「保存」。
- iOS：本项目为纯 Android 工程，未做 iOS 版本（需求已确认仅安卓）。
