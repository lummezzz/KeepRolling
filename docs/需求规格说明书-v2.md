## ① 项目概述
一款地面交通微观模拟器 App。**v2 交互定位：像「画图 App」一样极简**——竖屏全屏、无标题栏、无背景条，
所有操作靠少量图标按钮 + 手势完成，视线始终不被 UI 遮挡。

**相对 v1 的核心变化**：
| 维度 | v1 | v2 |
|---|---|---|
| 屏幕 | 横屏、顶部标题栏、底部工具栏 | **竖屏全屏、无标题栏、底部悬浮图标区**（无背景条） |
| 出入口 | 入口(绿)/出口(橙)分开，各占节点 | **统一为「开放路口」**：既是车辆生成点，也是目的地 |
| 目的地 | 随机选出口 | **按路口热度加权**：热度 / Σ热度 = 目的地概率 |
| 车型/速度 | 滑块设置比例 + 两档离散速度 | **三段式双滑块 + 正态分布曲线**（均值可拖、σ 可捏合缩放） |
| 道路 | 两点直线 | **网格吸附 + 直线/曲线两种样式**（曲线可拖拽调曲率） |
| 画路手势 | 点两下 | **单指按住 1.5s 不动 → 滑动预览 → 抬手生成** |
| 起点终点状态 | 无可视化 | **断头路=圆形停止符号；开放路口=双向箭头符号** |

## ② 用户画像

## ④ 页面文字原型（三大状态 + 一个对话框）

### S1 主界面（默认状态）
- **背景**：温润白（#FAF8F3 暖白），**较密网格**（网格线极浅，约 10m 一格）【AI建议：间距 10m，后续可在设置调整】
- **顶部**：**完全空白，无标题、无任何元素**
- **底部**：三个**无背景条**的悬浮圆形图标按钮，居中横排：
  - ▶ **开始**（teal 绿）→ 点击后开始模拟，图标变为 ⏸ **暂停**；再点暂停 → 停止模拟
  - ✎ **编辑**（灰）→ 进入编辑模式（背景转浅灰）
  - ⚙ **设置**（灰）→ 上方浮出 **保存**、**加载** 两个图标按钮
- **画布**：显示已建路网、车辆、以及道路端点符号
- **手势**：单指拖动 = 平移画布；双指 = 缩放 + 平移

### S2 编辑模式
- **背景**：浅灰（#F1EFE8，与主界面形成模式区分）
- **底部**：图标变为 **道路** + **返回** 两个按钮
- **点「道路」**→ 上方浮出 **直线**、**曲线** 两个图标按钮；选择后「道路」按钮图标变为对应样式（表示当前正在画哪种路）
- **画路操作（核心手势）**：
  1. 单指按住屏幕 **1.5 秒不动**（世界坐标不移动，容差约 12px）→ 起点出现**同心圆**，可带一次轻震动提示
  2. 保持按住并滑动 → 显示**临时预览道路**（虚线、半透明、始终朝向手指），手指处显示**同心圆**作为临时终点
  3. 抬手 → 起点终点均**吸附到最近网格交点**，生成最终道路（实线、完全不透明）。**预览态与最终态在颜色/线型上有明显区分**
- **点选道路**：道路上浮出 **删除** 按钮（图标）→ 删除该条道路，其它道路不受影响
- **点选断头路圆形停止符号**：浮出 **开放** 按钮 → 点击后圆形停止符号变为 **双向箭头符号**（表示可进出车辆），并弹出「出入口设置」对话框
- **点选双向箭头符号**：浮出 **封闭**、**设置** 两个按钮 → 设置 = 打开「出入口设置」；封闭 = 变回圆形停止符号（断头路，不再进出车辆）
- **点选曲线道路**：道路旁出现**拖拽手柄（圆点）**→ 拖动调整曲率（垂直于道路方向拖，限制 |弧高| ≤ 弦长一半）
- **点「返回」**：退出编辑模式，回到 S1（背景恢复温润白，底部恢复三按钮）

### S3 设置展开态
- 点击 ⚙ 后，其上方浮出 **保存**、**加载** 两个图标按钮
- 【AI建议】**长按 ⚙** 打开仿真参数面板（倍速 1x/2x/4x、反应时间、崩溃阈值）——避免这些能力在极简 UI 里无处安放

### D1 出入口设置对话框（底部/居中弹出卡片）
- 标题：图标 + 「出入口设置」
- **车辆生成**
  - 单滑块（整数值 1~10）：**a 秒/辆**（a=1 最快，a=10 最慢）
  - 双滑块（两个拖点切成三段）：**轿车 | 巴士 | 货车** 生成概率（三段宽度即比例，和为 100%）
  - 正态分布曲线（速度分布）：横轴 = 速度(km/h)，曲线 = 概率密度
    - **左右拖拽曲线** → 调整均值（默认 **60 km/h**）
    - **双指捏合** → 调整疏密（= 标准差 σ）【AI建议：σ 默认 10 km/h，范围 2~25】
- **路口热度**
  - 1~10 整数选择（步进/点选）
  - 显示换算后的概率：**该路口概率 = 自身热度 / 所有开放路口热度之和**
- 确认按钮（图标 ✓）/ 关闭按钮（图标 ✕）

## ⑧ 技术选型方案
（不变）Kotlin + Jetpack Compose + MVVM，仅 Android。本次新增的技术要点：

1. **路径抽象（曲线支持）**：道路从"直线段"升级为 `RoadPath` 抽象——
   `StraightPath`（网格点间线段）/ `ArcPath`（网格点间圆弧，由曲率参数算出圆心/半径/扫角）；
   提供 `length / pointAt(s) / tangentAt(s)` 三个方法，车辆位置与朝向统一由它决定，仿真内核无感。
2. **手势分层（互不冲突）**：
   - `detectTransformGestures`：双指缩放/平移（第二指按下即视为缩放意图）
   - 自定义 `awaitPointerEventScope`：单指按下 → 启动 1.5s 计时器（指针移动超容差则取消计时，转为平移）→ 计时到 → 进入"画路"状态 → 跟手预览 → 抬手提交
   - 单击 `detectTapGestures`：选择道路/符号
3. **网格吸附**：`snap(p) = round(p / GRID) * GRID`，起点终点与曲率手柄都走这个函数。
4. **节点符号状态机**：`NORMAL`（度≥2 的普通路口）/ `DEAD_END`（度1 的断头路，圆圈符号）/ `OPEN`（开放路口，双向箭头）。
   开放路口的配置 = `生成间隔 a 秒 + 车型三段比例 + 速度正态(μ,σ) + 热度 1~10`。
5. **目的地采样**：`P(目的地=j) = heat_j / Σ heat_k`（k 遍历除起点 j≠起点 的开放路口）【AI建议：排除自身，避免"原地生成又原地消失"】
6. **车辆规格**（按你的要求量化，可直接改常量）：
   - 统一车宽 W = 2.6 m（车道 3.5m，略小）
   - 轿车长 = 1.5W = 3.9 m；巴士 = 轿车×1.5 = 5.85 m；货车 = 轿车×2 = 7.8 m
   - 颜色：从一组低饱和高区分度的配色中随机取（同一辆车整个生命周期颜色固定）

## ⑨ 我补充的改进建议（均标注价值，请挑选）
1. **撤销/重做**：编辑模式下双指轻点 = 撤销上一步（画路/删除/开放都算一步）。手滑删了一条路不用重画。
2. **崩溃提示改为非遮挡横幅**：v1 的模态弹窗会挡住画面，看不清"是哪堵了"。改为底部红色横幅 + 闪烁路口高亮，点击横幅进入编辑。
3. **长按就绪震动反馈**：1.5s 计时到的那一刻轻震一下，用户明确知道"可以滑了"，是画路手感的关键细节。
4. **模拟中实时调参**：正在跑的时候点开放路口也能改生成频率/热度（不用停下重来），做"疏堵实验"的体验会好很多。
5. **车辆到达淡出**：车辆抵达目的地时原地淡出+轻微缩小，而不是凭空消失，观感更完整。
6. **保存/加载直接用**：v1 已经实现了完整存档逻辑，建议**别退化成占位按钮**，直接可用（按钮就在，不额外花时间）。
7. **网格吸附开关**：设置里加一个"自由放置（不吸附）"选项，画非网格路网的人会需要。
8. **性能保护**：车辆数 > 800 时自动简化渲染（去圆角、去车道虚线），保证老机型 60fps。
9. **视角复位**：双击空白处 = 恢复默认缩放并居中到路网包围盒中心。
10. **设置内统计面板**：车流数/累计生成/累计到达/平均速度放设置里，不占用主界面空间。
